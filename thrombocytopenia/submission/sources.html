70 distinct sources · 1,959 measurements (1,453 human, 497 animal) · NIH/NCATS OligoTox Challenge, Phase 2

Every measurement in this dataset carries a source_ref and an exact source_table locus — the specific table, figure, claim or label section a value was read from. This document is generated from the data, so it cannot list a source the dataset no longer uses or omit one it does. For each entry: the full citation, the database it was retrieved from, a resolving link, the rights class governing reuse, the number of rows it contributed, and how many distinct loci within it were cited.

How to read the row counts. "Rows" is the number of per-measurement records drawn from that source; "loci" is the number of distinct places within it that were cited. A source with 387 rows across 268 loci was mined cell-by-cell, not summarised — the two numbers together show extraction depth.

Rights position across the dataset

Two separate questions, and this page answers only the second. (1) May the source file be republished? (2) May the facts extracted from it be reused? A measured value read out of a copyrighted table is not the table. This classification is about extracted-fact reuse; nothing here licenses republication of a source document.

1,735 rows carry a publisher-declared or regulator-stated position permitting extracted-data release. 224 rows are on PROPOSED HOLD: no open licence was located, and the ruling belongs to the data owner. Zero rows withdrawn, zero rows cleared by this curation effort — the holds are proposed, not applied.

This ledger is a project classification, not legal clearance. It records what each publisher or regulator declares, with the basis, so the position is auditable rather than asserted. A permissive classification is taken from the article's own licence field, never from the fact that it is free to read. Rights are tracked per row, so a consumer can filter to the records matching their own determination. The per-regulator split matters: regulator document = government work = public domain reaches US federal agencies only. EMA permits reuse with attribution, and other national regulators are more restrictive still — one forbids redistribution without written approval and another reserves all rights. What is deliberately absent

No third-party full text is redistributed. Sources are referenced by identifier and exact locus; the PDFs and XML retrieved during extraction were working files and are not committed. What is committed is the curation record — every agent's returned rows, the adversarial-verification verdicts, and the source sweep — so the published tables are reproducible from their inputs rather than merely re-checkable against these citations.

Sources consulted but not used are not listed here. Two categories were deliberately excluded during curation: on-target antithrombotic pharmacology (aptamers that inhibit platelet function by design — that is the intended mechanism, not toxicity), and papers whose platelet content could not be pinned to a specific locus. A row whose exact locus could not be named was dropped rather than kept with a vague citation.
