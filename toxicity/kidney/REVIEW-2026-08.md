# Strict review — OligoTox kidney dataset

**Date:** 2026-08-28 · **Branch:** `claude/oligo-reorganize-toxicity-2h7t50` · **Reviewed state:** commit `43ed250`
plus the uncommitted working tree.

Every tracked file was read: the two source CSVs and the generated merge, `schema.md`, `METHODOLOGY.md`, `README.md`,
`PADP.md`, `PRESENTATION.md`, `SOURCES.md`, the three scripts, all 18 source PDFs and the three built deck
binaries. Six independent audit dimensions were run over that surface — data integrity, documentation-versus-data
drift, provenance rigour, scientific/domain correctness, presentation and naming, and allocation of work across the
Challenge's eight toxicities. Each candidate finding was then handed to a second pass whose task was to *refute* it
against the repository: recompute the count, open the PDF, read the cited line. Findings that did not survive were
dropped; several survived only with counts or severity corrected, and those corrections are carried below. Every count
here was recomputed from `data/*.csv` for this document, and every quoted PDF passage re-extracted with PyMuPDF rather
than taken on trust from the audit.

Where a finding below says something is absent from **the curated corpus**, that means the dataset and documentation as
they stood before this review: `data/`, `sources/`, `scripts/`, `METHODOLOGY.md`, `schema.md`, `PADP.md` and
`PRESENTATION.md`. It excludes the index layer this pass added — `toxicity/`, this report, and the register section
added to `README.md` — so the claim stays true as that layer grows.

## The headline

**The 21 patent-panel rows record the wrong species, and they are 19% of the dataset.** All 21 rows with `source_id =
N3` carry the identical tuple `species=mouse`, `system_model=mouse_7day_nephrotox_study`, `exposure_duration=7_days`,
`dose_or_conc_value=TBD`. They were extracted from Table 1 of US 11,105,794. The method behind that table is the
patent's *Measuring In Vivo Nephrotoxicity* section (PDF p.25): "Purpose bred Wistar Han Crl : WI ( Han ) male rats
obtained from Charles River Laboratories at 7 to 8 weeks of age were divided into groups of 4 ( table 1 , exp . A ) or
8 ( table 1 , exp . B )" — binding itself to Table 1 explicitly. The same paragraph gives the design: "dosed at 40 mg
/ kg on days 1 and 8 ( 2.5 ml / kg ) in the intrascapular region", biomarkers read on a "Multiplex MAP **Rat** Kidney
Toxicity Magnetic Bead Panel 2", and "On day 15 the rats were sacrificed". The patent does contain the phrase "seven
day mouse study" — I found it — but in a prophetic embodiment passage on stereodefined phosphorothioate linkages,
which says TD50 and EC50 "may be determined in mice in a seven day mouse study" and then offers rat, monkey, dog and
pig as alternatives. It is not the Table 1 experiment. The rows record a mouse where the source says rat, 7 days where
it says 15, and `TBD` for a dose it publishes. Correcting species alone moves the dataset from mouse 30 / rat 8 to
mouse 9 / rat 29 and falsifies the summary at `METHODOLOGY.md:146`.

**The repository's newest data file says the dataset is not yet fit for its stated purpose, and no front-facing
document mentions it.** `CLINICAL_VALIDATION.md:76` concludes, in bold: "**Until this field exists, the
dataset should not be used to train a nephrotoxicity model.**" It reaches that from a provenance/outcome confound (0
of 20 search-derived clinical rows reach grade ≥2 against 11 of 19 anchor-sourced rows, one-sided Fisher p = 4.5 ×
10⁻⁵, both reproduced here) and from seven direct source retrievals of which one survived as a measured negative.
`README.md`, `METHODOLOGY.md`, `schema.md`, `PADP.md` and `PRESENTATION.md` do not reference it. The only files in the
repository that now do are three dossiers added by this pass — `kidney-nephrotoxicity.md`,
`toxicity/immunotoxicity.md`, `toxicity/coagulopathy.md` — and this report.

**The "negative controls" claim is wrong twice over.** `PRESENTATION.md:680` and `:694` call the 27 grade-0 rows
"negative controls" and "known-SAFE negative controls"; `METHODOLOGY.md:153-155` describes them as spanning
"GalNAc-siRNA, siRNA, intrathecal ASO, and aptamer modalities". Wrong in composition: the 27 rows are ASO_gapmer 11,
GalNAc_siRNA 9, splice_switching_ASO 3, siRNA 2, aptamer 1, other 1 — the largest group is the gapmer class the deck's
own thesis calls nephrotoxic, and it goes unnamed, while "intrathecal ASO" is exactly one row. Wrong in kind: a
compound measured at a non-toxic exposure is a negative *observation*, not a designed control, and the validation file
at `:53-54` finds the negative class is "substantially *'nobody looked'* rather than *'looked and found nothing'*".

**Endpoint coverage against the Challenge's eight-toxicity list was nowhere stated until this pass.** The brief's
sentence — "Toxicities of interest include: Hepatotoxicity, kidney toxicity, thrombocytopenia, complement activation,
coagulopathy, immunotoxicity, chronic neurotoxicity, and hydrocephalus" — existed in the repository only inside a PDF,
and nothing recorded which of the eight had rows, which had PDFs acquired but unextracted, and which had nothing.
`toxicity/README.md` now carries that ledger: kidney delivered (111 rows), hepatotoxicity and immunotoxicity
sources-acquired-not-extracted, thrombocytopenia / complement activation / coagulopathy background-only, chronic
neurotoxicity and hydrocephalus not addressed.

## Corrections that need scientific sign-off, not curation

**This review did not modify `data/`.** No grade, species, unit, identifier or column was changed. That follows the
precedent the project set for itself: `CLINICAL_VALIDATION.md:5-7` records that "**Grades in
`measurements.csv` were NOT changed** — recommended reclassifications are recorded here for review, because
relabelling a toxicity dataset is a scientific call, not a curation one." The same reasoning covers everything below.

1. **The N3 species and study-design fields (B1).** Setting `species=rat` on 21 rows changes the dataset's headline
   species distribution and every document quoting it. The patent text is unambiguous, but the fields also encode
   modelling decisions — whether `system_model` should record the real 15-day, two-dose (d1, d8), 40 mg/kg
   intrascapular design, and whether the dose field should be filled from a protocol that dosed every compound
   identically. Confirm the Table 1 → method binding before 19% of the rows are rewritten.
2. **The `readout_category` typing of the same 21 rows (M9).** Either a retype to `histopathology`, or a new enum
   value for a graded in-vivo composite with `clinical_renal_outcome` redefined as human-only. A schema change with a
   rubric consequence — the grade-3 crosswalk (M20) hangs off the same rows — so it needs the same sign-off.
3. **`redistribution=verify` and `derived_features_only` (M14).** Marking the 36 `WS` rows `verify` would make the
   registry's own policy auditable, but conflates a rights question with a fact-verification question; the validation
   file's `renal_endpoints_measured` proposal is the better instrument. Which is adopted determines what the 47
   `public_domain` rows mean.
4. **Zero-padding MSR91–MSR99 (m16).** The one purely mechanical change here — nine keys, a regenerable merged CSV,
   one wrong citation at `SOURCES.md:222`. Still not applied: renaming primary keys in an externally cited
   dataset is a versioning decision, and it should land in one commit with the B1 corrections to the same 21 rows.
5. **The reclassifications the validation file already recommends** at `CLINICAL_VALIDATION.md:67-70`:
   MSR042, MSR063, MSR078, MSR044, MSR047 → `not_assessed`; MSR045 kept at 0 with an annotation; MSR066 given its
